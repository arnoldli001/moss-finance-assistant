# 情绪周期实战指南

> 本文件为 SKILL.md 规则5的扩展详解，包含情绪周期四阶段的**实战识别信号**、**典型龙头案例**、**仓位管理策略**与**常见陷阱规避**。

---

## 一、情绪周期完整循环图

```
  冰点期 ──回暖──▶ 回暖期 ──加速──▶ 高潮期
    ▲                                   │
    │                                   │
    └──────────退潮─────────────────────┘
         (崩溃后重新进入冰点)
```

**典型完整循环时长**：7-14个交易日（快熊快牛特征），最长不超过21个交易日。

---

## 二、冰点期（最冷时刻）

### 2.1 识别信号（满足任意4条即可确认）
- [ ] 涨停家数连续2日 < 30家
- [ ] 最高连板 ≤ 2板，且2板股次日无溢价甚至低开跌停
- [ ] 封板率 < 60%，炸板率 > 40%
- [ ] 跌停家数 > 15家，且包含前期连板高位股（A杀）
- [ ] 昨日涨停股今日平均收益率 < -2%（打板次日集体吃面）
- [ ] 市场高度连续3日压缩（如5板→3板→2板）
- [ ] 大盘日内V反失败，尾盘再次跳水

### 2.2 盘口特征
- 龙头股开盘秒跌停（没有任何承接）
- 新股破发/次新股连续跌停
- ST板块批量涨停（资金无处可去，炒垃圾避险）
- 成交量持续萎缩（上证<6000亿）

### 2.3 仓位策略
| 策略类型 | 仓位建议 | 具体操作 |
|---------|---------|---------|
| 激进型 | 10%-20% | 只做新题材首板试错，次日无论盈亏都走 |
| 稳健型 | 0%-10% | 空仓为主，或拿逆势抗跌的大金融/消费防御 |
| 新手型 | 0% | 直接休息，手痒就模拟盘，不要拿真钱练手 |

### 2.4 常见陷阱
- ❌ **陷阱1**：抄底高位股（觉得跌了很多了）—— 冰点期A杀无底部，腰斩后还能再腰斩
- ❌ **陷阱2**：接核按钮（觉得恐慌杀跌错杀了）—— 冰点期核按钮第二天还会有二连核
- ❌ **陷阱3**：逆势打板（觉得自己选的是好股）—— 情绪差时好股也会被带崩，覆巢无完卵

### 2.5 冰点结束信号（回暖触发点）
满足任意2条，说明冰点即将结束，可以开始寻找机会：
1. 某日午后出现"情绪逆转板"：龙头股从-8%拉到涨停（地天板），带领一批股翻红
2. 连板高度从2板突破到3板，且3板股次日有溢价
3. 跌停家数从>15家突然降到<5家
4. 大盘放量上涨>1%，且成交量比前一日放大30%以上

## 三、回暖期（播种季节）

### 3.1 识别信号（满足任意4条即可确认）
- [ ] 涨停家数回升至 30-60家
- [ ] 连板高度突破至 3-4板，且高度股次日能继续上冲
- [ ] 封板率 60%-75%，炸板率下降到 25%-40%
- [ ] 跌停家数 5-15家，A杀股减少
- [ ] 昨日涨停股今日平均收益率 > +1.5%（打板开始赚钱）
- [ ] 出现新题材：首板股批量出现（>5只）且有连板晋级
- [ ] 大盘成交量温和放大（上证6000-8000亿）

### 3.2 盘口特征
- 新题材龙头一字板/秒板，不给机会
- 补涨股批量首板，跟风吃肉
- 前一日炸板股有修复（低开高走翻红）
- 板块有持续性：第一天板块涨，第二天还能涨（不是一日游）

### 3.3 仓位策略
| 策略类型 | 仓位建议 | 具体操作 |
|---------|---------|---------|
| 激进型 | 50%-70% | 分2-3只：主仓位打新题材二板/三板龙头，副仓位做补涨首板 |
| 稳健型 | 30%-50% | 只做确定性最高的龙头低吸，不做跟风杂毛 |
| 新手型 | 20%-30% | 只做龙头首阴（龙头股第一次收阴线）低吸，不追高打板 |

### 3.4 核心选股策略（回暖期胜率最高的3种模式）
1. **新题材二板定龙头**：新题材启动日（首板5+只），次日优先打第一个晋级的二板股
2. **龙头接力三板**：回暖期第一个突破3板的股，大概率是总龙头，接力胜率>70%
3. **补涨龙挖掘**：龙头涨了3板后，找同板块同属性的低位首板/二板做补涨

### 3.5 常见陷阱
- ❌ **陷阱1**：还在做老题材龙头（上一轮周期的龙头）—— 老题材在回暖期是出货行情
- ❌ **陷阱2**：分散买10只杂毛（觉得买得多安全）—— 回暖期集中仓位干龙头，杂毛涨得慢跌得快
- ❌ **陷阱3**：见好就收太早（赚了5%就跑）—— 回暖期龙头有5-7板空间，不要卖飞

## 四、高潮期（全民狂欢）

### 4.1 识别信号（满足任意4条即可确认）
- [ ] 涨停家数 > 80家，甚至超过100家（百股涨停）
- [ ] 最高连板 ≥ 5板，龙头加速一字板不回头
- [ ] 封板率 > 80%，炸板率 < 20%（打板几乎必赚）
- [ ] 跌停家数 < 5家，几乎没有亏钱效应
- [ ] 昨日涨停股今日平均收益率 > +4%（打板次日吃大肉）
- [ ] 板块全面开花：主线涨，支线也涨，垃圾股也涨
- [ ] 成交量急剧放大（上证>9000亿甚至万亿）

### 4.2 盘口特征
- 龙头股连续一字板，散户排板买不到
- 连板股批量晋级：二板进三板率>50%
- 消息发酵极快：上午出的新闻，下午相关股全涨停
- "股神"变多：朋友圈/群里到处晒收益，新手也开始推荐股票

### 4.3 仓位策略
| 策略类型 | 仓位建议 | 具体操作 |
|---------|---------|---------|
| 激进型 | 70%-100%（满仓） | 只做龙头持股，不换股不折腾，直到龙头断板 |
| 稳健型 | 50%-70% | 龙头仓位不动，小仓位参与低位补涨 |
| 新手型 | 30%-50% | 只持有已经在车上的票，不开新仓追高 |

### 4.4 高潮期的核心：只卖不买（持仓者的天堂，追高者的坟场）
- ✅ **正确姿势**：持有龙头不松手，不开新仓，随时准备跑路
- ❌ **错误姿势**：看到赚钱效应好，加本金/借钱冲进去追高接盘

### 4.5 高潮结束信号（退潮触发点）
出现任意1条，都要高度警惕，开始逐步减仓：
1. **龙头炸板**：连续一字/加速的龙头，某天突然高开低走放巨量收阴线
2. **尾盘炸板潮**：14:30以后批量涨停股开板跳水，封板率从>80%骤降到<50%
3. **跌停数量翻倍**：前日<5家跌停，当日突然>10家，且是高位连板股跌停
4. **券商板块冲高回落**：牛市旗手券商突然跳水，往往是大调整前奏
5. **市场出现"最后一涨"板块**：白酒/医药等防御板块突然大涨（资金从题材撤退躲进防御）

## 五、退潮期（落袋为安）

### 5.1 识别信号（满足任意4条即可确认）
- [ ] 涨停家数从>80家逐日递减到30家以下
- [ ] 连板高度从≥5板逐日压缩到≤2板（高度坍塌）
- [ ] 封板率从>80%递减到<60%，炸板率飙升到>40%
- [ ] 跌停家数从<5家飙升到>20家，A杀批量出现
- [ ] 昨日涨停股今日平均收益率 < -3%（打板次日集体吃大面）
- [ ] 板块轮动极快：今天涨的板块明天直接低开闷杀，无一连胜
- [ ] 大盘放量下跌>1%，或连续阴跌

### 5.2 盘口特征
- 龙头断板后A杀（从涨停到跌停连续），没有任何反弹
- 补涨股成为最后一棒：龙头倒了，补涨股拉板，次日也是一字跌停
- 核按钮到处飞：开盘就有10+只股跌停，且封单一字排死
- 炸板股次日直接一字跌停（前一天炸板吃面，第二天还被闷杀）

### 5.3 仓位策略
| 策略类型 | 仓位建议 | 具体操作 |
|---------|---------|---------|
| 激进型 | 10%-30% | 空仓为主，最多做做超跌首板（情绪冰点前的试错） |
| 稳健型 | 0%-10% | 清仓看戏，手里一股不留 |
| 新手型 | 0% | 直接卸载软件，休息1-2周，等下一轮回暖 |

### 5.4 退潮期绝对禁止的操作（违者必亏）
1. ❌ **禁止追高打板**：任何板都不要打，尤其是高位连板，90%概率炸板或次日闷杀
2. ❌ **禁止抄底高位股**：龙头跌了30%就去抄？底在地下室，地下室还有十八层
3. ❌ **禁止补仓摊低成本**：越补越跌，越跌越补，最后满仓套牢
4. ❌ **禁止做T降本**：退潮期做T大概率T反，低吸被埋，高吸更惨
5. ❌ **禁止幻想反弹**："应该差不多了吧？"——退潮期比你想象的更久、更狠

### 5.5 退潮期正确姿势：防守反击
1. **第一时间清仓高位股**：不要等反弹，跌停前卖出就是胜利
2. **空仓等待**：管住手，机会是等出来的，不是做出来的
3. **观察新方向**：退潮期逆势抗跌、甚至能涨停的板块/个股，很可能是下一轮周期的主线
4. **复盘总结**：把这一轮周期的操作记录下来，赚的亏的都写清楚，为下一轮做准备

## 六、跨周期通用纪律（无论哪个阶段都必须遵守）

### 6.1 仓位纪律
- 单只个股仓位不超过总资金的 30%
- 打板操作单日最多 2 只，杜绝开超市
- 连续亏损 3 笔，强制空仓 1 天冷静

### 6.2 止损纪律
- 打板失败（炸板未回封）：次日开盘无条件止损，不幻想不补仓
- 接力失败（高开低走收大阴）：当日尾盘或次日开盘止损，亏损上限 -8%
- 任何个股：从买入价回撤超 -10% 无条件砍仓，绝不深套

### 6.3 止盈纪律
- 连板股：断板不回封卖出 50%，次日不反包清仓剩余
- 首板/二板：次日冲高不板就卖，不贪最后一个铜板
- 盈利超 +30%：分批止盈，至少卖出一半锁定利润

## 七、情绪周期指标速查表

| 指标 | 冰点期 | 回暖期 | 高潮期 | 退潮期 |
|-----|-------|-------|-------|-------|
| 涨停数 | <30 | 30-60 | >80 | 80→30↓ |
| 连板高度 | ≤2板 | 3-4板 | ≥5板 | 5→2↓ |
| 封板率 | <60% | 60-75% | >80% | 80→60%↓ |
| 炸板率 | >40% | 25-40% | <20% | 20→40%↑ |
| 跌停数 | >15 | 5-15 | <5 | 5→20↑ |
| 昨涨停今均收益 | <-2% | >+1.5% | >+4% | <-3% |
| 操作建议 | 空仓/试错 | 积极进攻 | 持股为主 | 清仓休息 |
