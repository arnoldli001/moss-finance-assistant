# SKILL.md — 昨日非涨停股票买卖策略技能

> Agent 每次运行时读取此 skill，把猜测替换为确定的规则。
> 本 skill 专注于**昨日未涨停**的股票筛选与买卖策略制定，区别于涨停板打板策略，
> 核心逻辑是「提前埋伏、低吸高抛、不追高、重安全边际」，适合风险偏好中等的投资者。

## 适用场景
本技能适用于用户提出以下相关问题时自动加载：
1. 昨日未涨停股票筛选（优质非涨停股推荐）
2. 个股买卖策略（买入/卖出/观望信号、止损止盈位）
3. 低吸潜伏策略（回调到位、即将启动的标的）
4. 抄底策略（超跌反弹、底部确认标的）
5. 价值投资选股（基本面优秀、技术面配合的中长线标的）
6. 仓位管理与加减仓时机建议

## 核心规则（硬性约定，不可违背）

### 规则1：昨日非涨停定义与初筛标准
必须先确认股票**昨日收盘价 < 昨日涨停价**（即昨日确实未涨停），才纳入本skill分析范围。

**初筛五维过滤（全部满足才进入下一步分析）：**
| 维度 | 筛选标准 | 排除情形 |
|------|---------|---------|
| **1. 非涨停确认** | 昨日涨幅 < 昨日涨停幅度（主板9.5%/科创板18%/创业板18%） | ❌ 昨日涨停（含炸板回封）的一律排除 |
| **2. 流动性** | 昨日成交额 ≥ 5000万元 | ❌ 成交额<5000万（流动性差，进出困难） |
| **3. 非ST** | 股票名称不含ST、*ST | ❌ ST/*ST（退市风险大） |
| **4. 非停牌** | 当前正常交易状态 | ❌ 停牌中（无法交易） |
| **5. 非新股** | 上市日期 ≥ 60个交易日 | ❌ 上市<60天（无历史K线参考） |

> **补充**：若用户指定某只股票分析，即使不符合初筛标准也要分析，但必须明确标注「该股不符合初筛标准第X条，风险较高」。

### 规则2：技术面四维评分体系（买入信号判定）
对每只通过初筛的股票，从以下4个技术维度打分（每项0-25分），总分100分：

| 维度 | 评分标准（满分25） | 数据获取方式 |
|------|-------------------|-------------|
| **1. 趋势形态（25分）** | ①均线多头排列（5/10/20/60日均线向上发散）=20-25分；②均线粘合向上发散=15-19分；③均线缠绕但20日均线向上=10-14分；④20日均线向下=0-9分；⑤底部形态（W底/头肩底/双底确认）额外+5分 | K线图均线分析 |
| **2. 量价配合（25分）** | ①放量上涨+缩量回调（近5日）=20-25分；②温和放量上涨=15-19分；③量价背离（价涨量缩/价跌量增）=5-9分；④缩量阴跌=0-4分；⑤突破前高放量≥1.5倍额外+5分 | 成交量+价格对比 |
| **3. 指标共振（25分）** | ①MACD金叉+KDJ金叉+RSI(50-70)=20-25分；②任意2个指标金叉=12-19分；③1个指标金叉=5-11分；④MACD死叉或KDJ超买(J>100)=0-4分；⑤布林带中轨上方运行额外+3分 | MACD/KDJ/RSI/BOLL |
| **4. 位置安全（25分）** | ①股价位于近60日低位区间（0-30%分位）=20-25分；②中位区间（30%-70%分位）=12-19分；③高位区间（70%-90%分位）=5-11分；④近60日新高附近（>90%分位）=0-4分；⑤距离强支撑位≤3%额外+5分 | 近60日高低点百分位 |

**买入信号评级（综合得分）：**
- ≥80分：**强烈买入信号** — 可分批建仓（建议首仓30%-50%）
- 60-79分：**买入信号** — 轻仓试探（建议首仓20%-30%）
- 40-59分：**观望信号** — 等待更明确信号（回调至支撑位或指标进一步走好）
- <40分：**回避信号** — 暂不考虑买入

### 规则3：基本面三维验证（加分项，提高胜率）
技术面评分≥60分的股票，叠加基本面验证，满足每项+5分（技术面总分上限仍为100分，超出部分计入「基本面加分池」，用于排序优先级）：

| 维度 | 加分标准（每项+5分） | 数据来源 |
|------|---------------------|---------|
| **估值安全** | PE≤行业均值80% 或 PB≤行业均值80%；ROE(TTM)≥15% | 财务数据/行业对比 |
| **业绩增长** | 近1季度营收增速≥20% 或 净利润增速≥30%；业绩预告预增 | 财报/业绩预告 |
| **机构持仓** | 近1季度机构持仓比例提升≥5% 或 北向资金近10日净流入≥1% | 机构持仓/北向数据 |

### 规则5：卖出信号判定规则
持仓股票出现以下任一情况，触发卖出信号（分为减仓/清仓两级）：

**🔴 清仓信号（无条件卖出）：**
1. 跌破关键支撑位（20日均线或前期低点）且当日无法收回（收盘价低于支撑位）
2. MACD高位死叉 + KDJ死叉 + 放量下跌（成交量≥5日均量1.5倍）
3. 出现利空公告（业绩大幅下修/监管处罚/大股东大额减持≥5%）
4. 止损位触发（见规则5止损设置）

**🟡 减仓信号（减仓50%，剩余仓位观察）：**
1. 达到第一止盈位（见规则5止盈设置）
2. 连续2日缩量滞涨（价格波动≤1%，成交量<5日均量70%）
3. KDJ超买（J值>100持续2天）+ 长上影线（上影线≥实体2倍）
4. 触及强压力位（前期高点/布林带上轨）且放量回落

**🟢 继续持有信号：**
1. 均线多头排列 + 成交量温和放大
2. MACD红柱持续放大 或 绿柱持续缩小
3. 回调未破5日均线，且5日均线持续向上

### 规则6：止损止盈量化设置
**止损位设置（刚性执行，不抱幻想）：**
| 买入类型 | 止损位 | 说明 |
|---------|-------|------|
| 低吸回调买入 | 买入价下方 5% 或 20日均线下方 2%（取两者较高值） | 跌破无条件止损 |
| 突破确认买入 | 突破K线的最低点下方 2% | 假突破立即止损 |
| 抄底买入 | 前低下方 3% | 创新低立即止损 |
| **最大止损红线** | **任何单笔亏损不超过总资金的 2%** | 这是绝对底线 |

**止盈位设置（分批止盈，不贪心）：**
| 止盈阶段 | 目标位 | 操作 |
|---------|-------|------|
| **第一止盈位** | 买入价 +8% ~ +10% | 卖出50%仓位，收回成本或大部分利润 |
| **第二止盈位** | 买入价 +15% ~ +20% | 再卖出30%仓位，剩余20%看趋势 |
| **第三止盈位（利润奔跑）** | 用移动止盈：收盘价跌破5日均线卖剩余20% | 让利润充分增长 |

> **注意**：若买入后快速拉升3天涨幅≥15%，立即触发第一止盈位（不必等目标价），防止获利回吐。

### 规则7：仓位管理金字塔原则
严格执行金字塔仓位原则，不可一次性满仓单只股票：

| 技术面评级 | 单只股票最大仓位占比 | 建仓节奏 |
|-----------|-------------------|---------|
| 强烈买入（≥80分） | ≤ 总资金 15% | 分3批：首仓50%→回调加30%→确认趋势加20% |
| 买入信号（60-79分） | ≤ 总资金 8% | 分2批：首仓60%→确认加40% |
| 观望（40-59分） | 0%（不操作） | 等待信号明确再考虑 |
| 回避（<40分） | 0%（坚决不买） | — |

**单行业/概念最大仓位 ≤ 总资金 30%**（防止行业黑天鹅）

### 规则8：大盘环境过滤
大盘环境决定仓位总水位，任何买入策略必须叠加此过滤：

| 大盘环境（上证指数） | 仓位总水位上限 | 操作策略 |
|---------------------|--------------|---------|
| 均线多头（20/60日均线向上） | 80% ~ 100% | 积极操作，按规则6满配 |
| 震荡市（20/60日均线缠绕） | 40% ~ 60% | 降低单票仓位，快进快出 |
| 均线空头（20/60日均线向下） | 0% ~ 30% | 仅轻仓抄底超跌股，或直接空仓 |
| 当日暴跌（跌幅≥2%） | 立即降至≤20% | 不抄底，等待止跌信号 |
| 当日暴涨（涨幅≥3%） | 不追高，维持原仓位 | 次日大概率分化，不追涨 |

## 分析流程（Chain-of-Thought）

1. **大盘环境判定（规则7）**：
   - 获取上证指数最新点位、涨跌幅、20/60日均线方向
   - 判定当前大盘环境（均线多头/震荡/空头/暴跌/暴涨）
   - 确定仓位总水位上限，作为后续所有买入建议的前提约束

2. **昨日非涨停初筛（规则1）**：
   - 从候选股票池中，逐一确认昨日收盘价 < 昨日涨停价（关键！）
   - 按五维过滤（非涨停/流动性/非ST/非停牌/非新股）筛选
   - 输出通过初筛的股票清单，并标注每只不符合项（若有）

3. **技术面四维打分（规则2）**：
   - 对每只通过初筛的股票，按趋势形态/量价配合/指标共振/位置安全四维度逐一打分
   - 计算综合得分，给出买入信号评级（强烈买入/买入/观望/回避）
   - 剔除<40分的回避标的

4. **基本面加分验证（规则3）**：
   - 对技术面≥60分的股票，叠加估值/业绩/机构持仓三维验证
   - 计算「基本面加分池」分数，用于后续排序优先级

5. **买卖策略制定（规则4-6）**：
   - 按「技术分+基本面加分池」排序取TOP3-5只重点推荐
   - 为每只推荐个股设置：买入区间、仓位建议、分批建仓节奏（规则6）
   - 量化设置止损位与分批止盈位（规则5）
   - 列出需监控的卖出信号清单（规则4）

6. **已持仓个股卖出评估**：
   - 若用户提及已持仓个股，对照规则4的清仓/减仓/持有信号逐一检查
   - 给出明确的操作建议与触发条件

7. **纪律与风险输出**：
   - 汇总操作纪律清单（必须做/警惕/禁止三类）
   - 列出风险提示
   - **末尾必须附带双重风险声明**（通用投资声明 + 非涨停策略风险声明）

## 我们不这么做（因为那次事故）

### 事故1：把昨日炸板（未回封）当成「非涨停」推荐低吸
- **事故**：某股昨日盘中触及涨停但收盘炸板-5%，Agent 误认为是「昨日非涨停+超跌」推荐抄底，结果次日继续跌停，合计亏损-15%
- **规则**：昨日炸板股（最高价触及涨停但收盘未封住）即使收盘价<涨停价，也**不纳入**本skill推荐范围（除非距炸板已≥3个交易日且充分调整），因为炸板股往往套牢盘巨大，短期难涨
- **代码位置**：本 SKILL 规则1，补充过滤条件：昨日最高价=涨停价 且 收盘价<涨停价（炸板）的排除，除非距炸板≥3天

### 事故2：不设止损硬扛导致深套
- **事故**：某股买入后下跌8%触发止损位，但Agent建议「再等等看反弹」，结果继续下跌30%，用户深套
- **规则**：止损位是刚性纪律，跌破即无条件执行，任何「等反弹」「再看看」的想法都是错误的；规则5明确标注「刚性执行，不抱幻想」
- **代码位置**：本 SKILL 规则5 止损位设置 + 输出格式操作纪律「必须做到」第1条

### 事故3：单票满仓遇黑天鹅
- **事故**：用户满仓单只股票（占总资金100%），当晚公告财务造假，次日连续3个跌停，亏损30%+
- **规则**：强烈买入评级的单票最大仓位≤15%，任何情况下不得超过20%（规则6）；单行业仓位≤30%分散风险
- **代码位置**：本 SKILL 规则6 仓位管理金字塔原则

### 事故4：均线空头市场积极操作导致连续亏损
- **事故**：20/60日均线明显向下（熊市阶段），Agent 仍按技术面打分推荐买入，结果买一个套一个，连续5笔止损
- **规则**：大盘环境均线空头时，仓位总水位≤30%（规则7），甚至直接空仓；大盘过滤优先级高于个股技术面评分
- **代码位置**：本 SKILL 规则7 大盘环境过滤（规则7优先级 > 规则2个股评分）

### 事故5：追高近60日新高股，结果站岗
- **事故**：某股处于近60日95%分位（即将新高），Agent推荐「突破买入」，结果假突破后一路下跌20%
- **规则**：位置安全维度中，近60日高位区间（>70%分位）得分≤11分，>90%分位直接0-4分（规则2）；操作纪律「坚决禁止」第3条明确禁止追高买入
- **代码位置**：本 SKILL 规则2 维度4位置安全评分标准 + 输出格式纪律清单禁止项第3条
