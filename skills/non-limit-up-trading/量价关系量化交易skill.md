# 量价关系量化交易 Skill

> 免责声明：本规则库仅为技术规则的量化整理，供策略研究与回测使用，不构成任何投资建议。投资有风险，入市需谨慎。

---

## 0. 策略世界观（规则前提）

1. 股票的实质是交易，交易的变化是供需关系，供需关系直接呈现在**量价**之中。
2. 量价是市场上最真实有效的指标，是所有技术指标的源泉。
3. 主力资金运作四阶段：**建仓 → 洗盘 → 拉升 → 出货**。建仓与出货必然放量（主力一买一卖），缩量只可能对应洗盘或拉升——这是全部缩量规则的逻辑基础。
4. 相对确定性来源于**辨识度**（人气与潜在买盘），势能表现在**力道与惯性**上。
5. 位置决定性质：同一形态在低位是吸筹、在高位是出货（如烂板、托单）。

## 1. 基础量柱定义（量化口径）

| 术语 | 量化定义（默认参数，可调） |
|---|---|
| 高量 | 当日成交量 > 前3日成交量的最大值（`V > max(V[-1],V[-2],V[-3])`）；不分阴阳、不看颜色 |
| 高量定三天 | 出现高量后，以高量K线实体高/低点为观察锚，观察其后3天走势定性 |
| 缩量 | 当日成交量 < 前一日成交量（严格缩量可用 `V < 0.8 * V[-1]`） |
| 缩倍量 | 当日成交量 ≤ 前一日（或区间最高量）的 1/2；连续3日递减视为缩倍 |
| 倍量 | 当日成交量 ≥ 前一日成交量的 2 倍 |
| 梯量 | 连续3天及以上成交量递减（上涨梯量=风险；下跌梯量=机会） |
| 平量 | 当日成交量与前一日偏差 < 10% |
| 地量 | 区间（如20日）内最低成交量；注意"地量不等于地价" |
| 爆量 | 当日成交量 > 近20日最大量 × 1.5（或创阶段天量） |
| 高量支撑线 | 以最近高量K线的**实体低点**为支撑位 |
| 高量压力线 | 以过往高量K线的**实体高/低点**为压力位 |
| 大长腿 | 下影线长度 ≥ K线实体 × 2 |
| 大阴/大阳线 | 涨跌幅绝对值 ≥ 7% |

## 2. 量价关系 16 形态判定矩阵

> 判定维度：趋势方向（涨/跌）× 价格速率（加速/减速）× 量能（放/缩/平）。输出为信号方向与操作建议。

### 2.1 单根K线（8类）

| # | 形态 | 量化条件 | 含义 | 信号 |
|---|---|---|---|---|
| 1 | 放量大阳 | 涨幅≥7% 且 放量 | 分歧中买方获胜，建仓初期 | 看多 |
| 2 | 缩量大阳 | 涨幅≥7% 且 缩量 | 卖盘枯竭、追涨意愿强，拉升阶段 | 看多 |
| 3 | 放量大阴 | 跌幅≥7% 且 放量 | 抛压大，高位主力出货 | 看空 |
| 4 | 缩量大阴 | 跌幅≥7% 且 缩量 | 一致看空、恐慌砸盘，下跌中继 | 看空 |
| 5 | 放量小阴小阳 | 振幅<3% 且 放量 | 分歧巨大打成平手，顶/底反转区 | 反转预警 |
| 6 | 缩量小阴小阳 | 振幅<3% 且 缩量 | 量价匹配、无方向，横盘整理 | 观望 |
| 7 | 放量大阴大阳（宽幅） | 振幅≥10% 且 放量 | 趋势延续：上升中继续涨 / 下降中继续跌 | 顺势 |
| 8 | 缩量大阴大阳（宽幅） | 振幅≥10% 且 缩量 | 高控盘：上升途中=洗盘续涨；高位横盘=出货风险 | 位置定信号 |

### 2.2 多根K线组合（8类）

| # | 形态 | 量化条件（3日窗口） | 含义 | 信号 |
|---|---|---|---|---|
| 9 | 价升量缩 | 价涨减速 + 量能递减 | 量价背离，买方动能不足，将回踩但幅度有限 | 回踩后再多 |
| 10 | 量缩微跌 | 价小跌 + 量能递减 | 卖方减弱无人愿卖，洗盘特征 | 看多（洗盘） |
| 11 | 放量滞涨 | 价涨减速 + 量能递增 | 高位抛压增大，即将反转 | 减仓/清仓 |
| 12 | 放量微跌 | 价跌减速 + 量能递增 | 低位承接资金进场，见底信号 | 反转预警（多） |
| 13 | 缩量大涨 | 价涨加速 + 量能递减 | 分歧转一致，抛压减弱锁仓 | 强看多 |
| 14 | 缩量大跌 | 价跌加速 + 量能递减 | 多头崩溃、恐慌一致看空 | 强看空 |
| 15 | 放量大涨 | 价涨加速 + 量能递增 | 量价齐升、放量攻击 | 看多延续 |
| 16 | 放量大跌 | 价跌加速 + 量能递增 | 空头肆虐、承接不住，高位出货信号 | 看空 |
| — | 平量滞涨 | 价涨减速 + 平量且高量 | 卖方增加、抛压加重，见顶变盘 | 减仓 |
| — | 平量价缩（下跌中） | 价跌减速 + 平量且高量 | 仅小反弹非反转，不可抄底 | 观望 |
| — | 平量大涨 | 价涨加速 + 平量偏缩 | 空方减弱锁仓等加速，顶部将现天量 | 看多但备顶 |
| — | 平量大跌 | 价跌加速 + 平量偏缩 | 一致看空争相逃命 | 看空加速 |

**合成规则**：上涨放量+下跌缩量 = 健康上升趋势；上涨无量+下跌放量 = 见顶信号。

## 3. 高量柱战法（攻防体系）

### 3.1 高量柱定性

- 高量柱 = 大资金杰作 = 拐点 = 改变方向；是多空搏杀最激烈、单日资金堆积最多之处。
- 分类（按位置）：底部高量柱 / 中继高量柱 / 接力高量柱 / 顶部出货高量柱。
- 分类（按特点）：标杆高量柱、梯量高量柱、缩量高量柱、倍量高量柱；最优组合为"倍量伸缩高量柱"与"高量+缩倍组合"。
- 功能：抢筹（拉升前最后建仓/换庄）、洗盘（中继高量配合高抛低吸）、测试市场（高量次日缩倍=休克测试抛压）。

### 3.2 取用与画线规则

1. 左侧、水平、最近、最高（相对），依序取用；跳空补空、先者优先（量堆合并）。
2. 高量柱**实顶=安全线，实底=风险线**；实体较小时取虚顶/虚底（先取实后取虚）。
3. 上行找顶做安全线，下行找底做风险线；大阴大阳取二分之一位。
4. 风险线与安全线分三级：一级日常交易、二级加减仓响应、三级平仓/重仓响应。
5. 口诀：`过顶穿底换周期（风险，观望）`；`遇顶不过应回落，触顶不穿该上攻`；`实底一破快平仓`；`实顶一过可狙击`。

### 3.3 高量柱交易规则（量化条目）

| 规则 | 条件 | 动作 |
|---|---|---|
| 高量第1天 | 识别为高量 | 观望 |
| 高量第2、3天 | 价格在高量实体低点支撑线上方 | 阳上可参与 / 阴线观望 |
| 高量破 | 跌破高量实体低点 | 清仓（次日收阳则降级为观望） |
| 高量3天内 | 收上影线 / 高低点下移 | 减仓 |
| 高量3天内 | 缩量大长腿 | 观望 |
| 高量上影线被阳线实体突破 | 收盘站上 | 重点关注/加仓 |
| 下跌趋势第1次高量 | — | 诱多嫌疑，观望3天 |
| 下跌趋势间断3次高量后 | — | 机会信号 |
| 上涨趋势间断3次高量后 | — | 风险信号 |

## 4. 买入信号库（可编程条件）

### B1 左长黑右长红（洗盘结束+拉升启动）
- **形态**：左长黑 = 单根阴线跌幅>7%，或两根并列阴线合计跌幅>7%且每根>3%；右长红 = 大阳线涨幅≥7%。
- **位置**：一波拉升后的横盘末端，或趋势性上涨途中（主升浪）。
- **买入**：大阳线**次日收阳**为确认买点。
- **止损**：大阳线收盘价（跌破离场）。
- **思考参数**：大小K线之间的小K线天数越少确定性越高（建议≤5天，回测标定）。

### B2 进击K线（洗盘结束的诱空确认）
- **前置**：已有建仓+洗盘行为；分时快速拉高又快速回落、高位出货不多、均价线下方弱势震荡（诱空分时）。
- **条件**：重新拉起突破前方高点或逼近高点。
- **买点**：次日低开或开盘后快速回踩。
- **止损**：进击K线当日最低点。

### B3 阴线反包法（涨停后的反包）
- **前置**：涨停板无明显放量（主力高度控盘）。
- **条件**：阴线当日成交量 ≥ 涨停日成交量 × 2（越大越好）。
- **竞价确认**：9:15–9:25 出现"一气呵成"或"缓慢上攻"竞价模式。
- **分时买点（三选一）**：
  - A：高开小幅上冲后回落，不破昨收，快速上穿均价线并站稳，分时出现大单买入 → 买；
  - B：高开后回落在均价线获支撑，大单出现 → 买；
  - C：小幅低开（≥-3%）后白线急速拉升翻红，回落均价线获支撑，大单出现 → 买。

### B4 涨停回调低吸（注册制战法）
- **选股**：低位首板涨停（自然板非一字板）+ 分时站上均价线 + 换手率≥3% + 市值≤300亿。
- **定义**：情绪释放点 = 涨停当日（最高+最低）/ 2 区域（亦可用实体1/2）；支撑位 = 涨停当日最低价。
- **进场**：回调≥3天，阴线跌破情绪释放点，尾盘进场。
- **出场**：连续3根阴线不能创新高，尾盘出场；收盘破支撑位无条件离场。
- **止损**：破支撑（3–5个点）。

### B5 新屠龙刀战法
1. 低位首板涨停，成交量未放大；
2. 次日冲高回落，收放量大阴线；
3. 随后缩量调整（3–5天）不破首板低点；
4. 大阳线放量拔地而起 → 跟随进场。
- **进场**：情绪释放点 + 启动阳线；**出场**：成功则破5日线离场，失败则破支撑止损（3–5点）。

### B6 恐慌洗盘（低位长下影博弈）
- **条件**：盘中下影线跌破重要支撑位（幅度越大越好、影线越长越好、恐慌量越大越好），随后缓慢拉升，收盘收回支撑位上方。
- **逻辑**：恐慌止损盘不会在当日尾盘反人性买回 → 尾盘是短线博弈点。
- **买点**：当日尾盘试错进场。
- **验证**：次日盘中上影线突破前日收盘价（不验证则离场）。

### B7 均线金叉共振（波段进场）
- **信号**：5/10日均线金叉（空头排列后的首次金叉）。
- **过滤**：金叉时股价已连续上涨多日 → 不追高，等回踩。
- **买点**：回踩5日线企稳，出现阳包阴确认 → 进场。
- **反向**：死叉后不杀跌，等共振反弹1–3天再处理。
- **级别**：5/10日线共振窗口1–3天；60/120日线共振窗口≥20天。

### B8 飞龙在天（主升浪箱体突破）
- **前置**：第一波上涨有力度——≥2连板（实体板）或连续大阳累计涨幅≈30%，且明显放量；当前处于横盘箱体。
- **信号K线**：箱体内出现长下影K线（下影线 ≥ 实体×2，越长越好）。
- **买点**：激进者长下影当日14:55尾盘买入；稳健者次日突破箱体上沿买入。

### B9 龙回头（龙头第二波）
- **前置**：第一波≥2连板或波段涨幅≈30%（越大越好），放量。
- **回头形态**：高低点不断下移呈"A"字型，成交量逐步萎缩（量能=动能衰减）。
- **转折信号**：连续下跌后出现长下影K线（下影 ≥ 实体×2）。
- **支撑确认**：次日涨跌幅在±2%以内的小阴/小阳（越小越好）→ 支撑有效；若贴近下影线最低价则放弃。
- **买点**：确认日尾盘14:55买入；**止损**：跌破下影线最低价。

### B10 涨停连阳线
- **形态**：低位/上升趋势中涨停后，5日线上方连续小阳线或十字星横盘。
- **量能**：整理区间不跌破5日线；某日量缩至区间最高量一半以下（地量K线）。
- **买点**：地量当日尾盘或次日逢低低吸；**止损**：跌破5日线。

### B11 三阴不破阳
- **形态**：涨停后连续3根小阴线，不跌破涨停板最低价（高开则以前收为准），且三阴量必须萎缩。
- **买点**：成交量再次放大、突破1号K线（涨停）最高点 → 突破买点。
- **止损**：跌破3号K线最低点。

### B12 涨停揉搓线
- **形态**：涨停次日出现长上影线（拉高试盘有压力）+长下影线（打压回踩有承接）。
- **约束**：后续不得跌破长下影最低价；缩量小幅上扬时重点关注。
- **买点**：长下影K线之后逢低低吸；**止损**：跌破长下影K线最低点。

### B13 涨停缩倍量
- **形态**：涨停（放量换手板，越大越好）后5日内成交量缩至最高量一半以下。
- **买点**：再次放量突破换手板收盘价；**止损**：跌破缩量回踩最低点。

### B14 潜伏首板
- **前置**：先有大阳线或涨停板（所在题材为近期热点风口）。
- **过程**：洗盘期间资金连续吸筹（吸筹城墙：价格横盘+量柱连续），随后缩量 → 洗盘末端。
- **公式**：`主力操盘成本线不破 + 上方吸筹 = 大阳线或涨停板`。
- **板块确认**：板块内多只个股同步出现吸筹城墙 → 板块级行情，权重上调。

### B15 一进二（首板→二板）
- **条件**：① 有主力资金痕迹（大阳线/吸筹动作）；② 所在题材无跌停（市场情绪无低潮）；③ 首板有实力（封板质量高）。
- **买点**：竞价买点（当日主流方向）/ 盘中买点（分时九类稳定结构）/ 打板买点（关注成交量）。
- **打板风控**：成交量不得超过近期最大量（防打板失败）；成交量以正常量为佳（未放量的涨停=控盘）。

## 5. 卖出/风控信号库

### S1 分时相对卖点（三类）
1. **做多动能衰竭**：开盘直线拉升未封板（减仓点）；价创新高但量缩（量价背离，大概率回落）；高开震荡+缩量 → 走向下跌。
2. **诱多陷阱**：无量拉升；涨停破板先减仓（落袋为安），随后缩量拉升确认离场；横盘震荡击穿下沿、回抽不过 → 跳水离场。
3. **一致转分歧**：一次破板减仓、二次破板必须减仓；高位反复烂板=离场行为；早盘放量+尾盘偷袭放量 → 次日易低开闷杀，提前减。

### S2 日线级别卖点
- 平低开跳水 / 高开跳水 → 竞价卖出。
- **爆量离场**：爆量往往意味着调整开始（爆量后要么调整要么下跌；若爆量后转强则按"弱转强"另案处理）。
- **锁筹跳水**：平台跌破往往大跌 → 离场。

### S3 缩量阴线风控法（当天不抄底）
- **规则**：当日缩量阴线 = 洗盘未达效果，次日盘中大概率跌破当日收盘价。
- **执行**：缩量阴线当天不买入；次日盘中再择机。
- **适用**：下跌行情有效性更高，上涨行情慎用。

### S4 缩量阳线持股法（当天不卖出）
- **规则**：当日缩量阳线 = 拉升未达主力目标位，次日盘中大概率突破当日收盘价。
- **执行**：缩量阳线当天不卖，次日盘中拉升再卖。
- **适用**：上涨行情有效性更高，下跌行情慎用。

### S5 保护线体系（止损/止盈落地）
- **止损保护线（固定）**：设在最近支撑位（以筹码峰峰谷为参考），有效跌破即止损卖出。
- **拉升中途介入**：止损线 = max(最近上涨阳线最低点, 最近筹码峰峰谷)；两层都击穿必须止损。
- **止盈保护线（移动）**：设在最近一条上涨阳线低点或筹码峰峰谷，取较高者为第一参考；若最近上涨K线为短实体星线（分歧线），则以上一条起涨阳线低点为保护线。
- **机构股**：用筹码峰波谷做移动止盈可吃完整趋势；新手可用"有效跌破60日线"防守；老手用趋势背离卖点。

### S6 高量纪律
- 高量破（跌破实体低点）→ 清仓。
- 上影线触碰过往高量压力线过不去 → 减仓。
- 高量3天内高低点下移 → 减仓。
- 连红≥4天后见放量阴线 → 减仓。
- 量大实体小（高位）→ 有人跑，减仓。
- 技术信号相互矛盾 → 优先观望。

## 6. 主力行为识别（分时/盘口特征 → 量化特征）

### 6.1 吸筹判断（拉升吸筹/试盘）
- 开盘后自由震荡，随后拉升幅度 > 3%；
- 3–5分钟快速直线拉升（定位主力）；
- 必须放量（不放量=诱多陷阱）；
- 价格横盘 + 量柱连续出现 = 吸筹行为。

### 6.2 洗盘确认（主力维护）
- **时间**：个股横盘 > 30分钟；
- **空间**：横盘振幅 ≤ 3%；
- **现象**：价格线围绕均价线自由震荡、不随大盘波动（主力控盘维护）；
- **买点①**：放量突破前期横盘高点；
- **买点②**：突破后回踩前横盘高点不破。
- **V型维护**：开盘拉升>3% → 震荡 → 突然跌破均价线后 ≤5分钟 快速收回 → 反复回踩均价线不破 → 买点=回踩均价线不破（跌破不收回=主力放弃拉升）。

### 6.3 主力操盘成本线（基准线五形态）
1. 大阳线：以**开盘价**为基准线；
2. 大阳线：以**实体1/2**为基准线；
3. 相邻两根大阳线：以**第一根开盘价**为基准线；
4. 跳空缺口：以**前一根收盘价**为基准线；
5. 长下影大阳线：取下影区域成本密集位（实盘可用当日均价近似）。
- **规则**：成本线不破，任何下跌视为洗盘；成本线 = 止损线。
- **用途**：判断主力来没来（力道）、多不多（数量）、走不走（出逃/加仓）、强不强（同属性对比）。

### 6.4 十大经典分时形态（特征标签）
| 类别 | 形态 | 关键量化特征 | 策略倾向 |
|---|---|---|---|
| 建仓 | 脉冲建仓 | 尖角波、间歇性大单放量 | 回调低吸（波谷抬高时） |
| 建仓 | 冲击建仓 | 流畅短促波形+持续大单，回调不破均价线；底部当日涨≈3%、量比>2 | 短线抢反弹 |
| 建仓 | 攻击建仓 | 持续密集大买单直线拉升（多封板） | 等洗盘后低吸，不追 |
| 试盘 | 向上试盘 | 瞬间拉升后归平静，单笔/数笔大单放量 | 底部区域=中线建仓机会 |
| 试盘 | 向下试盘 | 早盘瞬间打压后归平静，大单放量 | 测支撑，底部=建仓机会 |
| 诱多 | 早盘诱多 | 开盘10分钟大单对敲冲高，15分钟后减弱，量峰横向放大无力度 | 观望/卖出 |
| 诱多 | 盘中诱多 | 无温和放量铺垫的突然暴拉，量峰先横放后急缩 | 减仓 |
| 诱多 | 尾盘诱多 | 小单拉高大单卖出，新高即有抛单 | 次日低开概率大，卖出 |
| 洗盘 | 强势洗盘 | 高开后持续回落，反抽不过均价线；若放量→下行空间大 | 减仓/清仓，等底部反转 |
| 洗盘 | 弱势洗盘 | 平缓回落+大幅缩量，底部有承接 | 重点关注，短中线机会 |
| 承接 | Y字承接 | V字价 + 底部量能构成Y形（红酒杯），低位反复出现 | 轻仓参与/等反转 |
| 护盘 | 尾盘护盘 | 全天走低尾盘加速下跌现Y字承接+放量，位于成本区/关键支撑 | 洗盘尾声，次日量价齐升则进 |
| 诱空 | 盘中/开盘诱空 | 震荡造恐慌、日内无明显放量、收盘站上均价线；K线留长影/探底线 | 理想买点（洗盘末期） |
| 抢筹 | 尖角抢筹 | 尖角波持续上涨，回调不到均价线，均价线持续上行 | 回调逢低买进 |
| 拉升 | 强势拉升 | 高开高走/平开后突拉封板，均价线高位，封板强 | 最具时间价值的参与位 |
| 出货 | 高开出货 | 竞价拉板诱多→高开低走，均价线一路走低 | 开盘早卖，反弹清仓 |
| 出货 | 拉高出货 | 锯齿形，量价背离（越拉量越小），小单拉大单砸 | 持币观望 |

### 6.5 盘口五单（Level-2 特征）
- **托单**：买档挂单 > 卖档 ×10 → 高位=警惕出货，低位=吸筹；
- **压单**：卖档挂单 > 买档 ×10 → 多为制造恐慌，结合K线位置判断；
- **夹单**：上下大单夹中间小单 → 洗盘手法；大单消失=变盘信号；
- **堆单**：买卖均为四位数大单 → 消耗耐心，多见于大蓝筹；
- **卡单**：夹单+堆单结合，一边小单一边大单 → 主力隐藏痕迹，勿搞反吸筹/出货方向。

## 7. 操盘口诀（浓缩规则）

| 口诀 | 量化解读 |
|---|---|
| 价格慢慢涨，量能慢慢放 | 温和放量上涨 = 主力建仓吃货 |
| 量大实体小，多半有人跑 | 高量+小实体（高位）= 出货嫌疑，减仓 |
| 大量缩量破，拿住准没错 | 缩量过前高（高量峰）= 洗盘充分，持股 |
| 大量次日阴，仓位全出清 | 巨量次日收阴 = 出货套人，清仓 |
| 大跌反弹第一次，直接建仓要出事 | 首次反弹套牢盘抛压重，不抄底 |
| 价不过高量过高，进去就是接飞刀 | 价格未过高量顶而量先过 = 有人急跑，回避 |
| 阳线破一半，该换就得换；阳线破开盘，很难再反弹 | 大阳线实体1/2与开盘价是关键防守位 |
| 缺口只要不灌破，前高早晚都会过 | 跳空缺口不回补 = 强势延续 |
| 高量破，有灾祸 | 跌破高量实体低点 = 清仓 |
| 高量不分阴阳 | 量柱分析不看K线颜色 |
| 下影线越多越长，下跌概率越大 | 频繁长下影 = 风险累积 |

## 8. 量化实现框架（伪代码）

```python
# ---------- 基础量柱 ----------
def is_high_volume(v, i, lookback=3):
    return v[i] > max(v[i-lookback:i])

def is_shrink(v, i, ratio=1.0):
    return v[i] < v[i-1] * ratio          # ratio=0.5 即缩倍

def is_double(v, i):
    return v[i] >= v[i-1] * 2

def ladder_volume(v, i, n=3):              # 连续n天递减
    return all(v[i-k] < v[i-k-1] for k in range(n))

# ---------- 高量柱攻防 ----------
def high_volume_lines(df, i):
    body_top = max(df.open[i], df.close[i])   # 实顶=安全线
    body_bot = min(df.open[i], df.close[i])   # 实底=风险线
    return body_top, body_bot

# 高量破 → 清仓
if close < body_bot: signal = "CLEAR"
# 高量后2-3天站在支撑线上方且收阳 → 可参与
elif days_since_hv in (2, 3) and close > body_bot and is_yang: signal = "LONG"

# ---------- 左长黑右长红 (B1) ----------
left_black  = pct_chg[i-1] <= -7 or (two_bar_combined_drop <= -7 and each <= -3)
right_red   = pct_chg[i] >= 7
confirm     = pct_chg[i+1] > 0                     # 次日收阳确认
position_ok = in_consolidation_after_rally or in_main_uptrend
if left_black and right_red and confirm and position_ok:
    buy(); stop_loss = close_of_right_red

# ---------- 缩量阴线风控 (S3) ----------
if is_yin[i] and v[i] < v[i-1]:
    no_buy_today()        # 次日盘中大概率破今日收盘

# ---------- 缩量阳线持股 (S4) ----------
if is_yang[i] and v[i] < v[i-1]:
    hold()                # 次日盘中大概率过今日收盘

# ---------- 涨停回调低吸 (B4) ----------
if first_limit_up and turnover >= 3% and mktcap <= 30e9:
    emo_point = (high[day0] + low[day0]) / 2
    support   = low[day0]
    if pullback_days >= 3 and is_yin and close < emo_point:
        buy_at_close()
    if three_yin_no_new_high: exit()
    if close < support:     stop()

# ---------- 保护线 (S5) ----------
stop_line  = max(last_up_bar_low, chip_peak_valley)   # 中途介入
trail_line = max(last_rally_bar_low, chip_peak_valley) # 移动止盈
if close < stop_line:  stop_loss()
if close < trail_line and main_force_distribution_done: take_profit()

# ---------- 分时洗盘确认 (6.2) ----------
if sideways_minutes > 30 and amplitude <= 3% and around_vwap:
    if volume_breakout(sideways_high): buy()           # 放量突破
    if pullback_hold(sideways_high):   buy()           # 回踩不破

# ---------- V型维护 ----------
if open_rally > 3% and break_vwap and recover_within(5, "min"):
    if retest_vwap_holds: buy()
```

## 10. 组合与优先级（实战决策顺序）

1. **先定趋势**：均线排列 + 量价合成规则（上涨放量/下跌缩量=健康）。
2. **再定位置**：低位/中继/高位（同一形态位置决定性质）。
3. **高量定锚**：最近高量柱画安全线/风险线，定三级响应。
4. **信号触发**：买入库 B1–B15 任一满足且位置匹配 → 候选。
5. **风控过滤**：S3 缩量阴线风控（当天不买）、S6 高量纪律、技术矛盾优先观望。
6. **板块验证**：板块内多股同步出现吸筹/突破结构，信号加权。
7. **仓位与退出**：保护线体系（固定止损 + 移动止盈），机构股用趋势防守，短线股一波完事。

## 11. 已知局限与使用注意

- 多数规则源于主力行为学经验归纳，**必须先回测标定参数**再上实盘；不同市场阶段（注册制、涨跌幅限制差异）阈值需调整。
- 缩量阴线/阳线规则为**盘中概率优势**，非收盘保证；缩量阴线在下跌市有效性更高，缩量阳线在上涨市有效性更高。
- 打板、一进二类信号依赖盘口/竞价数据（Level-2），日线数据无法完整复现。
- 烂板、托单、诱多等信号强依赖"位置"判断，需先解决位置量化（如距N日高/低点幅度分位）。
- 所有信号在**技术矛盾时优先观望**，宁可错过不可做错。
