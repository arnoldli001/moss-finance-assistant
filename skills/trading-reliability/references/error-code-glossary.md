# 交易所/券商错误码映射表（Error Code Glossary）
本文件用于将第三方（交易所、券商）返回的原始错误码，映射为系统内部统一的错误类型和提示。
## 1. 通用映射（模拟）
| 原始错误码 | 来源 | 系统内部归类 | 是否重试 | 熔断动作 |
| :--- | :--- | :--- | :--- | :--- |
| `-1001` | 券商网关 | `TIMEOUT` | ❌ 否 | 触发 Gateway 熔断 |
| `-1002` | 券商网关 | `NETWORK_ERROR` | ✅ 读重试 / ❌ 写不重试 | 记录失败率 |
| `20001` | 交易所 | `PRICE_OUT_OF_LIMIT` | ❌ 否 | 无 |
| `20002` | 交易所 | `INSUFFICIENT_BALANCE` | ❌ 否 | 暂停该策略交易 |
| `30001` | 交易所 | `ORDER_NOT_FOUND` | ✅ 是（查询时） | 无 |
| `40001` | 交易所 | `RATE_LIMIT_EXCEEDED` | ⚠️ 延迟重试 | 开启该接口限流器 |
| `50001` | 交易所 | `CANCELLATION_LIMIT_EXCEEDED` | ❌ 否 | **熔断该合约交易（当日）** |

## 2. 风控系统内部错误码
| 内部码 | 名称 | 说明 | 用户提示 |
| :--- | :--- | :--- | :--- |
| `RISK-001` | `MAX_POSITION_EXCEEDED` | 持仓数量超过策略限额 | "当前标的持仓已满，禁止开仓" |
| `RISK-002` | `LOSS_CUT_TRIGGERED` | 达到止损线，禁止开仓或强制平仓 | "触发风控止损，交易暂停" |
| `RISK-003` | `ASSET_CHECK_FAILED` | 资金/持仓校验不一致 | "资产状态异常，请联系管理员" |
> **注意**：对于 `CANCELLATION_LIMIT_EXCEEDED`，系统必须在达到限制前（如 480/500 次）主动预警并停止高频撤单行为，而非等到被交易所拒绝。
