# SKILL.md — 大盘指数预测技能

> Agent 每次运行时读取此 skill，把猜测替换为确定的规则。
> 本 skill 用于"复盘预测"按钮：基于盘前新闻 + 盘前小作文两路输入，
> 给出上证指数、科创板、创业板的走势预测与个股应对策略。

## 适用场景
1. 复盘预测：盘前综合分析（新闻 + 小作文热度）→ 指数走势预测
2. 开盘策略制定：基于预测给出板块与个股应对建议
3. 风险预警：识别高开低走、低开高走等典型走势陷阱

## 核心规则（硬性约定，不可违背）

### 规则1：高开低走概率规则
- **条件**：上证指数 / 科创板 / 创业板 任一指数高开幅度 ≥ 0.3%
- **结论**：该指数当日有 80% 概率高开低走（即开盘高于全天均价，收盘低于开盘价）
- **应对**：
  - 不追高，等待回调后再考虑介入
  - 持仓者可在高开时分批减仓
  - 关注尾盘是否有资金回补
- **依据**：A股历史统计 — 高开 0.3% 以上当日高开低走频率约 80%

### 规则2：低开高走概率规则
- **条件**：任一指数低开幅度 ≥ 0.3%（即跌幅 ≥ 0.3%）
- **结论**：该指数当日有 65% 概率低开高走
- **应对**：
  - 不恐慌割肉，观察 10:30 前后资金流向
  - 若低开伴随利空消息，仍需谨慎，可能是真下跌
  - 关注低开后的量能变化，放量回升可考虑介入

### 规则3：平开（-0.3% ~ +0.3%）
- 走势需结合盘前新闻情绪与小作文热度综合判断
- 小作文热度 ≥ 8 分（满分10）且新闻偏利好的 → 偏多震荡
- 小作文热度 ≤ 4 分且新闻偏利空的 → 偏空震荡
### 规则4：大盘预测成交额低于2.2万亿，则关注辨识度参与热门个股或小盘连续涨停股，交易额预测大于2.4万亿则关注参与容量行业龙头个股。

## 分析流程（Chain-of-Thought）

1. **信息提取**：从盘前新闻结果中提取利好/利空个股清单、美股夜盘走势、宏观政策
2. **情绪判断**：从小作文热度结果中提取热度评分、关键词、讨论方向
3. **规则应用**：
   - 美股夜盘科技股大涨 → A股相关概念可能高开 → 应用规则1
   - 小作文热度极高 + 利好个股多 → 高开概率大
   - 美股大跌 + 利空新闻多 → 低开概率大 → 应用规则2
4. **指数预测**：分别给出上证、科创板、创业板的开盘与全天走势
5. **个股策略**：若用户提及个股，给出该股应对策略
6. **风险声明**：必须附带投资风险声明

## 信息来源要求
- 指数历史统计规则：来自A股长期统计，标注"历史统计规则"
- 实时数据：必须来自盘前新闻搜索结果，不可臆测
- 小作文热度：来自知识星球抓取的分析结果
- 不可靠信息：来自股吧/论坛的内容需标注"信息来源可靠性待验证"
