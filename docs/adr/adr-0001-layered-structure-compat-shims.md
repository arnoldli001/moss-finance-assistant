# ADR-0001: 新分层结构 + 兼容垫片（真源唯一）

- 状态：已接受
- 日期：2026-08-16（本记录 2026-08-31 补录）

## 背景

项目从单层 `agent/` 结构演进出 `shared/`、`governance/`、`orchestration/`、
`interfaces/` 等新分层目录。迁移期间出现同一逻辑存在两份实现（旧路径与新路径），
且新目录一度未纳入 git 跟踪，导致修改错位、覆盖无兜底。

## 决策

1. **真源唯一**：每段真实实现只保留一份，位置按分层归属（shared=通用能力、
   api=协议/中间件、orchestration=编排、governance=治理）。
2. **旧路径 = 兼容垫片**：`agent/` 等旧路径保留为 re-export 垫片，文件头标注
   `[兼容垫片]`，由 `shared/compat_bootstrap.py` 在运行时注册 sys.modules 别名。
3. **真源地图入库**：README 维护「项目结构（真源地图）」，改代码前先查地图。

## 后果

- 正面：消灭双实现漂移；旧调用方零改动渐进迁移。
- 负面：新贡献者需先理解垫片机制；垫片本身增加一层间接性。

## 替代方案

- 一次性全量改 import 并删除旧路径：迁移风险大、review 成本高，否决。
- 保留两份实现并人工同步：漂移风险已被历史验证，否决。
